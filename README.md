# Mortality-Surveillance-Analysis-PBI
Analyzing retrospective mortality surveillance data across demographic cohorts and peak risk periods  within 10 countries using Power BI
## Executive summary
This Mortality Surveillance project provides a Retrospective Mortality Surveillance Analysis across 10 selected countries to evaluate historical patterns of death and isolate apex threats across different demographic cohorts. Utilizing a dataset configured in Power BI, the analysis tracks key variables—including year, country, gender, age group, absolute death counts, and mortality rates—to provide public health leaders with the precise, data-driven evidence required to optimize resource allocation and reduce preventable deaths.

Mortality is heavily skewed toward males due to high exposure to external injuries and delayed medical care, with the 45–59 age cohort representing the highest risk window due to chronic disease accumulation. Chronological tracking reveals that these mortality risks are highly dynamic, showing an inconsistent, fluctuating trajectory that spiked in 2015 and rose again in 2026.

This retrospective analysis successfully translates raw mortality data into actionable visual intelligence via Power BI. To maximize life-saving impact, policymakers must move away from reactive models and implement ongoing, flexible tracking of death trends to dynamically deploy injury prevention programs, targeted screenings, and healthcare resources exactly where mortality risks surge.
